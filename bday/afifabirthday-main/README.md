# My Dearest Pages

Create an extraordinary, premium, cinematic interactive birthday website for my girlfriend.

IMPORTANT:

I have provided reference screenshots from an Instagram Reel. Use them as the primary visual and interaction inspiration.

I want the WEBSITE EXPERIENCE to feel similar to the reference:

- vintage romantic scrapbook

- cream paper

- pink/blush accents

- elegant serif typography

- handwritten/cursive typography

- photographs arranged like physical scrapbook photos

- envelopes

- letters

- gifts

- flowers

- vinyl record

- paper textures

- handwritten notes

- layered paper

- physical card/page animations

- cinematic transitions

DO NOT make a generic birthday landing page.

DO NOT simply create sections that scroll one after another.

Build a COMPLETE INTERACTIVE DIGITAL BIRTHDAY GIFT.

The feeling should be:

"Someone created an entire magical scrapbook just for me."
